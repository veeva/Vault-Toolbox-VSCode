# Vault Toolbox for Visual Studio Code

The Vault Toolbox Visual Studio Code extension is designed to make the everyday life of Vault
Admins and Developers easier. It leverages the power of the Vault REST API to integrate Vault
configuration, deployment, and debugging workflows directly into your local development
environment.

## Features

- **Environments**: Saving and connecting to multiple Vault environments, with basic, session ID,
  and API access token authentication
- **VQL Editor**: Running read-only VQL queries against Vault with syntax highlighting, a visual
  Query Builder, saved queries, and query history
- **Compare Environments**: Comparing MDL and Vault Java SDK code between two Vault environments
  and applying changes between them
- **MDL**: Syntax highlighting, extracting, deploying, and dropping MDL, plus downloading Vault
  Configuration Reports
- **Vault Java SDK Code**: Extracting, deploying, and deleting custom Vault Java SDK code
- **Developer Logs**: Downloading API Usage logs and SDK Runtime logs
- **API History**: Reviewing the Vault API calls Vault Toolbox makes, for troubleshooting
